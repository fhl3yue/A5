# 项目上下文恢复说明

本文档用于 Codex 上下文窗口压缩、开启新会话或交接队友时快速恢复项目状态。

## 1. 项目定位

项目题目方向为“景区导览服务 AI 数字人”。当前实现不是通用闲聊数字人，而是面向景区可配置知识库的导览服务平台。

当前演示景区为：灵山胜境。

核心表达建议：

- 标题保留为“景区导览 AI 数字人”。
- 页面显示“当前景区：灵山胜境”。
- 快捷问题来自当前景区知识库推荐问题。
- 管理后台支持切换或配置景区资料与数字人形象。

## 2. 项目目录与启动

项目根目录按实际克隆位置为准；当前机器示例为：

## 4. 数字人形象管理状态

题目要求中“数字人形象管理：可配置数字人的外观、服装、声音等，使其更贴合景区文化特色”更偏向管理后台能力，不是游客自由换装。

当前实现方向：

- 管理者在后台配置数字人。
- 游客端读取当前景区数字人配置并展示。
- 配置项包括名称、角色标题、服务景区、服饰主题、授权角色素材模式、声音、欢迎语。
- 新增配置项包括 `avatar_asset_url`、`fallback_message`、`service_boundary`、`video_provider_status`。
- 管理后台支持上传 PNG/WebP/AVIF/GIF/JPG 数字人图片素材，并自动更新游客端形象，透明背景优先。
- 管理后台支持查看外部数字人视频服务启用状态、最近状态、平均耗时、回退次数和最近失败原因。
- 后端保存数字人配置。
- 文本问答和语音问答的 TTS 会使用后台配置的声音。
- 如果取得第三方角色授权，可将透明 PNG 放置为 `frontend\assets\avatar\licensed-character.png`，并在后台服装主题中选择“授权角色素材”。

相关文件：

- `backend\app\models.py`

- `backend\app\services\digital_human.py`
- `backend\app\services\digital_video.py`
- `backend\app\services\audio.py`

- `backend\app\main.py`
- `frontend\index.html`
- `frontend\app.js`
- `frontend\styles.css`

- 管理端动态文本简体化展示：旧语音识别日志、热门问题、游客感受度报告和新问答结果会在展示层统一转为简体中文，避免简繁混排。
- 低显卡发行适配：FastAPI 数字人视频适配层、游客端视频优先播放和失败回退、Windows 云端页面启动器、Android WebView APK 壳。
- Windows 完整演示版打包脚本仍保留：`scripts\build_windows_demo.ps1`，产物目录为 `dist\scenic-ai-guide-demo`。

仍需如实说明的限制：

- 当前默认数字人是项目自制透明 PNG 立绘，前端保留 SVG/CSS 动效作为回退，不是 Live2D Cubism SDK 模型。
- 项目不内置初音未来或其他第三方 IP 素材；如需使用，必须先取得权利方授权并自行提供授权素材文件。
- 默认口型同步仍是“语音播放状态驱动的嘴部动画”；启用外部数字人视频服务后，可播放云端生成的口型视频。
- 管理员鉴权仍是演示 token。
- 管理后台已补知识库管理、游客感受度报告、基础趋势看板和数据大屏概览，但仍可继续增强多景区配置和正式权限体系。
